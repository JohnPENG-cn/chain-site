# 链条 5 页模板（v4）

2026-10-27 起 PCB 用这套；2026-10-28 起 HBM、CoWoS、铜也迁完，四条链都是 5 页，导航里没有“旧版式”了。
代码：`tpl/page_v4.py`（结构、导航、改道、PCB 渲染）、`tpl/page_v4g.py`（HBM / CoWoS / 铜共用的渲染：读 `<链>/page.py` 末尾的 `SPEC['v4']`——标题、一分钟看懂、五句话、主图、三个信号灯、②③④ 页摆哪些块、节标题问句）、`assets/reading.js`（导航 / 脚注 / 改道）、`assets/hig.css` 末尾一节（导航树样式）。
写作规则仍以 `docs/PLAIN_LANGUAGE.md`（说人话）、`docs/READING_MODE.md`（阅读模式 §12）为准，本文只讲“页怎么拆、怎么连”。

## 1. 五页各管什么

| # | 文件 | 页名 | 给谁 | 预算（手机 390px，默认收起时 main 里可见字数） |
|---|------|------|------|------|
| ① | `<链>.html` | 总览 | 所有人，一分钟看懂 | ≤ 2500 字，一张主图 |
| ② | `<链>-pattern.html` | 格局与钱在哪赚 | 想知道钱在哪 | ≈ ≤ 4000 字，≤ 3 张图，1 张主表，其余表收起 |
| ③ | `<链>-cycle.html` | 周期与产能 | 想知道会不会过剩 | ≈ ≤ 4000 字 |
| ④ | `<链>-track.html` | 主要矛盾追踪 | 每周回来看的人 | ≈ ≤ 4000 字；周五周报更新“现在读数” |
| ⑤ | `<链>-data.html` | 底稿与数据 | **给想核数的人** | 不限；宽表、拖动模型、对账、全部来源、名词 |
| + | `changelog.html` | 更新记录 | — | 版本说明、并入说明、旧版链接只放这里 |

总览固定结构：标题写出主要矛盾 → 一行“怎么读” → 一分钟看懂 → 五句话（每句标 事实 / 判断）→ 一张主图 + 一句图注 → 三个信号（现在读数 + 红黄绿灰灯）→ 什么会证明我们错 ×3 → 下一页。
灯色由代码按已有阈值现算（`render_v4` 里 `s1 / s3`），没有可靠公开数据的信号固定灰灯；阈值、主要矛盾、总账概率、X 系列草案**不在模板里改**，改要 John 确认。

## 2. 导航

* 配置只在 `tpl/page_v4.py` 顶部：`PAGES`（5 页：文件、页名、短名、一句话）、`OTHER`（其他链条）、`SITE`（总账、日报、原理图、更新记录）、`ALIAS`（旧锚点 → 没有同名块的去处）。
* `nav.rd-toc.sn#rdToc` 是服务端写好的整站树：链条 › 5 页（当前页 `a.pg.on`），当前页下面的 `#snHere` 由 `reading.js` 按 `main section[data-toc]` 填小节并做滚动高亮。
* ≥ 1200px：左侧常驻栏（§12 的 rail 位置）。< 1200px：顶栏 `#rdCur` 显示“页短名 · 当前小节”，点开是底部抽屉（标题“导航”），点链接、点空白、按 Esc 都会关。
* 每页（总览除外）顶部有 5 步条 `.pg-steps`，底部有上一页 / 下一页 `.pg-pn`。

## 3. 隐藏区与改道（为什么页面 JS 不用改）

`pcb.js / chain.js` 按固定 id 找节点画图填表，缺一个就报错。所以每页 main 后面带一个 `#ch-shadow`（`hidden inert aria-hidden`），里面原样放其他 4 页的块：脚本照常跑、镜像图（`data-mirror`）照常复制，读者看不到；字数、脚注、版面检查都不算它。
代价：每页 HTML 体积接近原单页（见风险）。

* 构建时：可见部分里 `#id` 链接若指向别的页，改成 `那一页.html#id`；来源 `#srcN` 一律改成 `<链>-data.html#srcN`。
* 运行时：`window.CH_HOME`（id → 所在页）。head 里的小脚本让旧网址 `pcb.html#旧锚点`、`pcb.html#srcN` 直接 `location.replace` 到新页；`reading.js` 对 JS 后渲染出来的 `#id` 链接做同样改道。
* `pcb-map.html` 仍跳 `pcb.html#…`，再由上面的脚本转一次（两跳）。
* 脚注弹层：本页隐藏区里有同一条来源时照样弹摘要，“在来源列表中查看 →”去底稿页。

## 4. 事实 / 判断标签

`label_and_limit()` 给正文段落（`p`，表格、侧栏、一分钟看懂、五句话、信号、要点版、callout、本章来源除外）加标签：

1. 有 `估` 标签，或出现判断用词（估、我们、本页、判断、可能、大概、更像、预计、看不出、推断、意味、提议、如果、若、应该、倾向、未必、不一定、说明、更可能、恐怕、风险、经验）→ **判断**；
2. 否则带数字或来源上标 → **事实**；
3. 都没有（操作说明、过渡句）→ 不标。

这是启发式，写新段落时请主动用判断用词表达判断，别把估算写成陈述句。总览五句话的标签是手写的（`OV5`），数字由 assert 保证在 BLUF / NUMS 里。

## 5. 脚注

* 每段（`p / li / dd / dt / td / th / figcaption / h1–h4 / summary / blockquote`，都不是就取最近的 `div`）最多 1 个上标：留第一个。
* 多出来的不删：进本章末尾折叠的「本章来源」（`.chsrc`）。JS 后渲染的块由 `reading.js` 的 `limit()` 在运行时做同样处理（`body[data-fnmax="1"]` 开启）。
* 图表下方的“来源”行（`.src-line`）不受限制。完整「来源与注释」只在底稿页 `#apx`。

## 6. 标题

节标题 ≤ 15 字、尽量是问句（`sec()` 里 assert）。`data-toc` = “编号 标题”。内容页可见文字里不许出现“旧版 / 并入 / v0.x”（assert；引用别的页版本号如“HBM 页 v0.4”放行）。

## 7. 验收

```
./build.sh                                  # 含 tools/overflow_check.py：所有 article 页 × 9 宽度 × 缩放，含导航检查（第 5 项）
python3 tools/page_stats.py <5 页> changelog.html   # 字数、390px 高度、脚注、表、图（默认 / 全展开）
```
另：浏览器里逐页看控制台无报错、镜像图有内容；旧 id 全部能在某页可见部分或 `ALIAS` 里找到（对照旧页 id 列表）。

## 8. 迁移一条旧链（HBM / CoWoS / 铜）步骤

1. 在 `<链>/page.py` SPEC 里设 `layout='v4'`。
2. 把 `tpl/page_v4.py` 里 PCB 专用的 `CHAIN / PAGES / DATA_PAGE / H1 / OV5 / 三个信号` 抽成按链传入的配置（目前写死 PCB，第一条迁移时顺手拆）。
3. 按第 1 节把已有章节分到 5 页；不删内容，只能搬或收起；每节标题改成 ≤ 15 字的问句。
4. 总览三个信号从该链主要矛盾 #1 的先行指标里取，灯色按已有阈值写成代码；没有阈值的不许新编，标灰并写“本页提议”。
5. 版本说明、并入说明、旧版链接搬进 `changelog.html`（按链分段）。
6. `OTHER` 里把该链改成 5 页子树；总账链接映射（`ledger/build.py` 的 `PAGE_MOVED`）指向追踪页。
7. 跑第 7 节验收，截图 390 / 1280 存 `shots/`（不提交）。

## 迁移一条链（2026-10-28 HBM / CoWoS / 铜的做法）

1. 在 `<链>/page.py` 末尾加 `SPEC.update(layout='v4', v4=dict(...))`：`h1`、`title0`、`one_min`（是什么 / 钱在哪 / 最大风险 / 盯什么 / 什么算我们错）、`ov5`、`ov_fig=(论点号, 问句)`、`sig`（三个灯，按 `data/<链>.json` 现算，阈值原样取自 `LOGIC['watch']`）、`sig_note`、`pattern / cycle / track`（`('step', 步骤id, 问句)`、`('arg', 论点号, 问句)`、`('cn'|'diff'|'claims'|'watch'|'wrong'|'pred', 问句)`）。底稿每一步都必须摆进某一页，否则构建报错。
2. 节标题 ≤ 15 字的问句（`sec()` 里 assert）；正文里的版本号（v0.x）、“旧版”“并入”字样会被 `assemble` 拦下，改成中性说法，版本细节写进 `<链>/build.py` 的 changelog。
3. 只搬不删：内容仍是 `LOGIC / SPEC` 原文；判断、证伪条件、预测台账、模型数字不动。
4. `ledger/build.py` 的 `PAGE_MOVED` 把旧页指到 `<链>-track.html`；旧网址 `<链>.html#锚点` 由 `CH_HOME` + `reading.js` 自动跳到新页。
5. 检查：`tools/overflow_check.py --pages <5 页> --widths 390 1280`（含静态导航检查），`tools/page_stats.py` 看默认可见字数与手机高度。
