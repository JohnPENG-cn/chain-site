# 说人话清单（Plain Language）

2026-10-26 起，所有研究页（先从 pcb.html 做起）都按这份清单写。John 的要求：**以读者为中心，小学生都能听懂**。
行业研究让人觉得遥远，常常是因为话太绕，而不是道理太深；更糟的是，话一绕，错的逻辑也被藏住了。

## 写之前

- [ ] **先给结论和“跟钱有什么关系”**：每段第一句就是要点，第二句说它对谁赚钱、谁亏钱。
- [ ] **主要矛盾不能变**：说人话只是翻译，不能改判断、总账概率和模型数字。改这些要 John 批准；有不同意见就单独标出来。

## 句子

- [ ] **一句只说一件事**。超过约 40 个字，或者有两个“；”，就拆开。
- [ ] **能念出来**：念一遍不打结、不用回头看，才算过。
- [ ] **少用“=”“→”“vs”当动词**：要写成“所以”“比”“会变成”。符号只用在表格和图注里。
- [ ] **用主动句，主语要具体**：写“10 家板厂花了 292 亿元”，不写“资本开支 292 亿”。

## 行话

- [ ] **第一次出现就解释**：正文里用 `gl("资本开支", "买厂房、机器的钱")`，在词后面就地加括号说明。
- [ ] **开篇放「名词小白版」**：用 `glossary([...])`，每个词一句话，能打比方的再加一个生活类比。
- [ ] **不留没解释的缩写**：CCL、ROIC、HVLP、ABF、BOM、pp、1H26 这些，要么在名词表里，要么就地解释。
- [ ] **数字带单位，也带“相当于”**：例如“毛利率 59%（每卖 100 元剩 59 元）”。

## 类比

- [ ] **类比只用来帮人理解，不能用来证明**。
- [ ] **类比不能扭曲机制**：用之前问一句“它在哪儿不像？”。不像的地方关键，就不用，或者在旁边写明。
  - 例：“整条街开面包店”能讲扩产周期，但讲不出“高端板和普通板是两种行情”，所以分档的事要另外说。
- [ ] **一段最多一个类比**。

## 逻辑自查（写完必做）

- [ ] **“A 所以 B”要有证据**：中间的环节在页里有没有？没有就补上，或者标 估。
- [ ] **相关不等于因果**：两件事同时发生，可能另有原因。例：2023 年 ROIC 下滑，有扩产的原因，也有消费电子需求变差的原因。
- [ ] **样本代表性**：结论如果只靠一家公司，或者只挑了“最好那家”，要写出来。
- [ ] **口径一致**：年度和单季、公司整体和 AI 业务、A 股和台股，不能直接比；要比就写明。
- [ ] **证伪条件要排除别的解释**。例：上游毛利率掉了，不一定是利润回到了板厂，也可能是全行业一起变差，所以要加上“而板厂没跟着掉”。
- [ ] **推断要标出来**：公司没拆过的数（例如“多出来的 14 个百分点来自涨价”），要写成“我们推断”。

## 页面组件（tpl/article.py）

| 助手 | 用在哪 |
|---|---|
| `one_min(lines)` | 开篇「一分钟看懂」，5 句话，依次回答：是什么 / 钱在哪 / 最大风险 / 盯什么 / 什么算我们错 |
| `glossary(items)` | 「名词小白版」，`items = [(词, 一句话解释, 类比或'')]`，默认折叠 |
| `gl(词, 解释)` | 正文第一次出现时就地解释 |
| `plain(text)` | 在专业表述（已入账判断原文、治理句）下面补一句“说人话”，原文不动 |
