铜：2027 年缺的是量，还是位置？

怎么读：先看“一分钟看懂”，再看五句话和一张图；想知道怎么盯、什么算我们错，看下面的三个信号。小号上标数字是来源，点一下就能看。看不懂的词查名词小白版。公开数据整理，不构成投资建议。

一分钟看懂
  1. 是什么2027 年全球精铜并不短缺（ICSG +368 千吨）1，可美国在关税悬而未决时囤了 1.6–2 百万吨，美国以外反而缺货（高盛 −220 千吨）——价格由"铜在哪"定，不由"有多少"定。
  2. 钱在哪钱几乎全被矿山拿走：现价约 14,500 美元/吨，90 分位全成本只有 7.7–8.8 千美元12；冶炼厂在倒贴，现货加工费 −272 美元，中国冶炼每吨亏 4,129 元。
  3. 最大风险美国精铜关税怎么定：价差 > 800 美元 = 最后一波铜进美国（偏牛）；价差连续 1 个月 < 0 = 熊市情景。
  4. 盯什么COMEX−LME 价差（现在约 +170）、美国以外可见库存（约 339 千吨）、现货加工费 TC（−272）。
  5. 什么算我们错关税未定时美国以外库存升破 50 万吨而价格不跌；或 2027-06 前现货 TC 回到 0 以上而冶炼没有大规模减产。

五句话说清楚

  1. 判断2027 年铜不缺"量"、缺"位置"：全球小过剩（约 +256 千吨）、美国以外小缺口（约 −144 千吨）；基准均价约 13,700 美元、先紧后松，低于远期和高盛。
  2. 判断缺不缺：全球精铜 2027 年小过剩：ICSG +368 千吨1，我们约 +256 估；但美国囤了 1.6–2 百万吨，美国以外是缺口（高盛 −220，我们约 −144 估）
  3. 判断卡在哪：约束在精矿，不在冶炼：冶炼想做 31.0 百万吨，精矿只够 29.71；TC 从 2015 年 107 美元跌到现货 −272。快变量是库存的位置：美国以外可见库存只有约 339 千吨（约 4.2 天）估
  4. 判断和市场差在哪：主流（高盛 15,400、远期 14,405）5 把中国废铜替代（+2,985）和资金持仓（+775）算进基本面；我们基准 13,700、概率加权 13,605 估，2027 年下半年比上半年松，2028 年方向向下
  5. 判断中国：中国消费占全球 59%1，2027 年需求基本零增长（麦格理）：地产投资 −20.6%、空调内销 −23.7%，电网 +4%；高价下中国在"让出"金属——9 月精铜进口 −16.7%、出口 +81%
